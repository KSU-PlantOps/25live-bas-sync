How to update

On the Docker host, in the folder with docker-compose.yml:

docker compose pull        # with image: ghcr.io/ksu-plantops/25live-bas-sync:1.3
docker compose up -d

# or, if it's built from the repository (build: .):
git pull
docker compose up -d --build

The container can't replace its own image — that would need the Docker socket, which is root on the host. To update automatically, the host can run those commands on a timer; see Updating automatically. Read the release's upgrade notes first.

Restart

Stops the service and starts it again — a few seconds, with nobody signed out. Settings made on these pages apply without it. Restart to load a renewed HTTPS certificate, after changing where logs or state are kept, or if something seems stuck.

It doesn't re-read the container's environment (.env): for that, run docker compose up -d on the host.
