API tokens

A token lets a program — an MCP server giving an AI assistant access, or a script — use the JSON API at {{ api_url }}. It may do what its role may, through the API only: it can't open these pages. Whatever its role, a token can never sync with Force, change the room map, settings, passwords or access, restart the service or stop a job. See docs/api.md.
