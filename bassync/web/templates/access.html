Setting up the app in Microsoft Entra
  1. Register it. Entra admin center → App registrations → New registration. Single tenant. Redirect URI: platform Web, {{ redirect }}.
  2. A secret. Certificates & secrets → New client secret. Paste its Value above, and put its expiry date in your calendar.
  3. Groups in the token. Token configuration → Add groups claim → Security groups. Under ID, choose Group ID (then enter object IDs here), or for groups synced from on-premises AD, sAMAccountName (then enter names like BAS_Admins). For large directories choose Groups assigned to the application instead and assign the groups under Enterprise applications → Users and groups; nested groups don't count there, so assign each group directly.
  4. The IDs. Copy the Directory (tenant) ID and Application (client) ID above.
  5. Try it in a private window: Sign in with Microsoft. Once it works for an Admin group, you can turn the local password off.
